HARDWARE / 01

Wiring architecture

Four conditioned EMG envelope outputs → ESP32 ADC inputs → five servo PWM outputs.

CORE EMG / SERVO PATH
!

Core wiring: use conditioned EMG ENV outputs, not raw electrodes. Confirm every signal stays within the ESP32 ADC input range. Power the servos from a separate regulated supply sized for the selected motors’ stall current, and connect the servo-supply ground, EMG ground and ESP32 GND together. Never power five servos from the ESP32 3.3 V pin.
